# Azure DevOps MCP tools in this session

Two Azure DevOps connections are attached to the session. Neither presents server-level MCP
instructions; the tool descriptions and parameter schemas below are what the session sees,
verbatim (captured 2026-10-14) except:

- the gateway's tool-name prefix is shortened to `mcp__MCP_DOCKER__azure-devops__`;
- `$schema` is removed, and so is `"additionalProperties": false`, which every gateway object
  schema carries (under it, a key the schema lacks, such as `format` on a single-item update,
  fails validation);
- only the tools for work items, links, iterations and queries are listed, and within them the
  parameters marked omitted, plus `excludedIds` on `work` and `asOf` on `wit_work_item`, are
  left out.

- Connection **gateway**: a self-hosted azure-devops MCP server behind a Docker MCP gateway. Tool
  names start `mcp__MCP_DOCKER__azure-devops__`.
- Connection **connector**: the claude.ai Azure DevOps connector. Tool names start
  `mcp__claude_ai_Azure_Devops__`.
